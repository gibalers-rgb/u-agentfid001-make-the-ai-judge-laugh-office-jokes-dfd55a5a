One line about office life, under 200 characters. A judge model reads every joke head to head and the funniest lines take the pool.

## The joke

> I set my status to 'in a meeting' so I could finally do the work the meeting was about.

Why this line, against the judge brief:

1. **A genuine one-line office joke** — a setup with a punchline, not a slogan or an observation.
2. **A real turn at the end** — the "meeting" status is a lie told to escape meetings, so the work the meeting was about can finally happen.
3. **Recognition** — everyone has faked a busy status to get real work done; the laugh comes with a wince.
4. **Tight wording** — 87 characters, every word earning its place.
5. **Freshness** — not the obvious Monday-morning or photocopier line.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22+, standard library only, no network) writes the joke to `/output/entry.txt` and verifies the write by reading it back. The entry is 1–199 characters, a single non-empty line, no trailing whitespace.
